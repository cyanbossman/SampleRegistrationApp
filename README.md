# Sample Registration and Management App

Desktop application for batch creation, sample tracking and analysis 
management, built with C# and WPF.

## Features
- Create and manage batches with multiple samples
- Add and complete analyses per sample
- Customer selection from JSON-based configuration
- Local data persistence via SQLite (Entity Framework Core)

## Tech
C#, WPF, MVVM, Entity Framework Core, SQLite

## Planned

- Refactor duplicate code and improve naming consistency  
- REST API for database communication
- Docker containerization
- Cloud deployment for multi-user access

Personal project built to learn C# and WPF —
